Variáveis e operadores

Tipos primitivos vivem na pilha. String é um objeto e usa equals() para comparar valor.

Variaveis.java 
public class Variaveis {
    public static void main(String[] args) {
        int idade = 25;
        double salario = 4500.50;
        String nome = "Ana";
        boolean ativo = true;

        // Operadores aritméticos
        int a = 10, b = 3;
        System.out.println(a + b);    // 13
        System.out.println(a / b);    // 3 (inteiro)
        System.out.println(a % b);    // 1 (resto)

        // Conversão de tipos
        double d = idade;              // widening automático
        int truncado = (int) 3.9;    // narrowing → 3

        System.out.printf("%s tem %d anos, salário R$%.2f%n",
            nome, idade, salario);
        System.out.println("Ativo: " + ativo);
        System.out.println("Truncado: " + truncado);
    }
}

Controle de Fluxo

Estruturas que controlam a ordem de execução: condicionais e laços.

if / else / switch 
public class Condicionais {
    public static void main(String[] args) {
        int nota = 75;

        if (nota >= 90) System.out.println("A");
        else if (nota >= 70) System.out.println("B");
        else System.out.println("Reprovado");

        // Switch expression (Java 14+)
        int dia = 3;
        String nomeDia = switch (dia) {
            case 1 -> "Segunda";
            case 2 -> "Terça";
            case 3 -> "Quarta";
            default -> "Outro";
        };
        System.out.println(nomeDia);
    }
}
Laços 
public class Lacos {
    public static void main(String[] args) {
        // for clássico
        System.out.print("for: ");
        for (int i = 0; i < 5; i++) System.out.print(i + " ");

        // while
        System.out.print("\nwhile: ");
        int j = 0;
        while (j < 5) System.out.print(j++ + " ");

        // break / continue
        System.out.print("\nimpares<7: ");
        for (int k = 0; k < 10; k++) {
            if (k == 7) break;
            if (k % 2 == 0) continue;
            System.out.print(k + " ");
        }
        System.out.println();
    }
}

04

Métodos

Métodos encapsulam comportamento reutilizável. Java passa primitivos por valor e referências de objeto também por valor — a referência é copiada, o objeto é compartilhado.

Métodos e Sobrecarga 
public class Metodos {

    // Sobrecarga: mesmo nome, parâmetros diferentes
    static int area(int lado) { return lado * lado; }

    static double area(double base, double altura) {
        return base * altura / 2;
    }

    // Passagem por valor vs referência
    static void dobrar(int x) { x *= 2; } // não afeta original
    static void dobrarArray(int[] arr) { arr[0] *= 2; } // afeta

    public static void main(String[] args) {
        System.out.println(area(5));
        System.out.println(area(4.0, 3.0));

        int n = 5;
        dobrar(n);
        System.out.println("primitivo após dobrar: " + n);

        int[] arr = {5, 10};
        dobrarArray(arr);
        System.out.println("array[0] após dobrar: " + arr[0]);
    }
}
05

Classes e Objetos

Classe é o molde; objeto é a instância. Atributos guardam estado, métodos definem comportamento. this referencia o objeto atual. Membros static pertencem à classe, não a instâncias.

Carro.java — classe completa 
public class Carro {
    private String marca;
    private String modelo;
    private int ano;
    private double velocidade;
    static int totalCarros = 0; // compartilhado pela classe

    public Carro(String marca, String modelo, int ano) {
        this.marca = marca;
        this.modelo = modelo;
        this.ano = ano;
        totalCarros++;
    }

    public void acelerar(double delta) { velocidade += delta; }
    public void frear(double delta) {
        velocidade = Math.max(0, velocidade - delta);
    }

    public String toString() {
        return marca + " " + modelo + " (" + ano + ") — "
             + velocidade + " km/h";
    }

    public static void main(String[] args) {
        Carro c1 = new Carro("Toyota", "Corolla", 2022);
        Carro c2 = new Carro("Honda", "Civic", 2023);

        c1.acelerar(60);
        c1.frear(15);

        System.out.println(c1);
        System.out.println(c2);
        System.out.println("Total de carros: " + Carro.totalCarros);
    }
}

ContaBancaria.java 
public class ContaBancaria {
    private String titular;
    private double saldo;

    public ContaBancaria(String titular, double saldoInicial) {
        this.titular = titular;
        this.saldo = saldoInicial > 0 ? saldoInicial : 0;
    }

    public String getTitular() { return titular; }
    public double getSaldo()   { return saldo; }

    public void depositar(double valor) {
        if (valor > 0) saldo += valor;
    }

    public boolean sacar(double valor) {
        if (valor > 0 && valor <= saldo) { saldo -= valor; return true; }
        return false;
    }

    public static void main(String[] args) {
        ContaBancaria c = new ContaBancaria("Maria", 1000);
        c.depositar(500);
        c.sacar(200);
        System.out.printf("Titular: %s | Saldo: R$%.2f%n",
            c.getTitular(), c.getSaldo());
        System.out.println("Tentando sacar R$2000: " + c.sacar(2000));
    }
}

Herança

extends cria uma hierarquia pai→filho. super acessa membros da superclasse. Java suporta herança simples — uma classe só pode estender uma outra.

Animal → Cachorro → Labrador 
class Animal {
    protected String nome;
    public Animal(String nome) { this.nome = nome; }
    public void emitirSom() { System.out.println(nome + " faz um som"); }
    public String toString()  { return "Animal: " + nome; }
}

class Cachorro extends Animal {
    private String raca;
    public Cachorro(String nome, String raca) {
        super(nome); // chama construtor do pai
        this.raca = raca;
    }
    @Override public void emitirSom() {
        System.out.println(nome + " late: Au au!");
    }
    @Override public String toString() {
        return super.toString() + " [" + raca + "]";
    }
}

public class HerancaDemo {
    public static void main(String[] args) {
        Animal a = new Animal("Genérico");
        Cachorro d = new Cachorro("Rex", "Labrador");

        a.emitirSom();
        d.emitirSom();
        System.out.println(a);
        System.out.println(d);
        System.out.println("Cachorro é Animal? " + (d instanceof Animal));
    }
}
08

Polimorfismo

Objetos de tipos diferentes respondem ao mesmo método de formas distintas. O método correto é escolhido em tempo de execução (binding dinâmico), não em compilação.

Polimorfismo e instanceof 
class Forma  { double area() { return 0; } }

class Circulo extends Forma {
    double raio;
    Circulo(double r) { raio = r; }
    @Override double area() { return Math.PI * raio * raio; }
}

class Retangulo extends Forma {
    double w, h;
    Retangulo(double w, double h) { this.w=w; this.h=h; }
    @Override double area() { return w * h; }
}

public class PolimorfismoDemo {
    public static void main(String[] args) {
        Forma[] formas = {
            new Circulo(5),
            new Retangulo(4, 6),
            new Circulo(3)
        };

        for (Forma f : formas) {
            String tipo = f.getClass().getSimpleName();
            System.out.printf("%s → área = %.2f%n", tipo, f.area());
        }

        // Downcasting seguro (pattern matching Java 16+)
        Forma x = new Circulo(7);
        if (x instanceof Circulo c) {
            System.out.println("Raio do círculo: " + c.raio);
        }
    }
}

Abstração

Classe abstrata não pode ser instanciada. Define um contrato parcial: métodos abstratos obrigam subclasses a fornecer implementação.

abstract class 
abstract class Veiculo {
    protected String nome;
    Veiculo(String nome) { this.nome = nome; }

    abstract double calcularConsumo(double km); // sem corpo

    void exibir() { // método concreto herdado
        System.out.printf("%s: %.2f L/100km%n",
            nome, calcularConsumo(100));
    }
}

class Moto extends Veiculo {
    double consumoPorKm;
    Moto(String n, double c) { super(n); consumoPorKm = c; }
    @Override double calcularConsumo(double km) { return consumoPorKm * km; }
}

class Caminhao extends Veiculo {
    double consumoPorKm;
    Caminhao(String n, double c) { super(n); consumoPorKm = c; }
    @Override double calcularConsumo(double km) { return consumoPorKm * km; }
}

public class AbstracaoDemo {
    public static void main(String[] args) {
        Veiculo[] frota = {
            new Moto("Honda CB 500", 0.04),
            new Caminhao("Volvo FH", 0.35)
        };
        for (Veiculo v : frota) v.exibir();
    }
}

Interfaces

Interface é um contrato 100% abstrato. Uma classe pode implementar múltiplas interfaces, resolvendo a limitação da herança simples.

interface + implements 
interface Pagavel {
    double calcularTotal();
    default String descricao() {
        return "Total: R$" + String.format("%.2f", calcularTotal());
    }
    static double comDesconto(double v, double pct) { return v*(1-pct/100); }
}

interface Imprimivel { void imprimir(); }

class Pedido implements Pagavel, Imprimivel {
    String produto; int qtd; double preco;
    Pedido(String p, int q, double u) { produto=p; qtd=q; preco=u; }
    @Override public double calcularTotal() { return qtd * preco; }
    @Override public void imprimir() {
        System.out.println(produto + " x" + qtd + " — " + descricao());
    }
}

public class InterfacesDemo {
    public static void main(String[] args) {
        Pedido p = new Pedido("Notebook", 2, 3500.0);
        p.imprimir();
        double desc = Pagavel.comDesconto(p.calcularTotal(), 10);
        System.out.printf("Com 10%% desconto: R$%.2f%n", desc);
    }
}

Exceções

RuntimeException e subclasses são unchecked. As demais são checked e devem ser tratadas ou declaradas com throws.

try / catch / finally / custom exception 
class SaldoInsuficienteException extends RuntimeException {
    double valor;
    SaldoInsuficienteException(double v) {
        super("Saldo insuficiente. Solicitado: R$" + v);
        valor = v;
    }
}

public class ExcecaoDemo {

    static int dividir(int a, int b) {
        if (b == 0) throw new ArithmeticException("Divisão por zero!");
        return a / b;
    }

    static void sacar(double saldo, double valor) {
        if (valor > saldo) throw new SaldoInsuficienteException(valor);
        System.out.println("Saque de R$" + valor + " efetuado.");
    }

    public static void main(String[] args) {
        try {
            dividir(10, 0);
        } catch (ArithmeticException e) {
            System.out.println("Erro: " + e.getMessage());
        } finally {
            System.out.println("finally sempre executa");
        }

        try {
            sacar(500, 200);
            sacar(500, 800); // lança exceção
        } catch (SaldoInsuficienteException e) {
            System.out.println(e.getMessage());
        }
    }
}

Generics

Generics permitem escrever código type-safe e reutilizável para qualquer tipo, eliminando casts desnecessários e erros em tempo de execução.

Classe genérica e método genérico 
class Par<A, B> {
    private final A primeiro;
    private final B segundo;
    Par(A a, B b) { primeiro=a; segundo=b; }
    A getPrimeiro() { return primeiro; }
    B getSegundo()  { return segundo; }
    @Override public String toString() {
        return "(" + primeiro + ", " + segundo + ")";
    }
}

public class GenericsDemo {

    static <T extends Comparable<T>> T maximo(T a, T b) {
        return a.compareTo(b) >= 0 ? a : b;
    }

    public static void main(String[] args) {
        Par<String, Integer> p = new Par<>("Java", 21);
        System.out.println(p);
        System.out.println("Primeiro: " + p.getPrimeiro());

        System.out.println("Máximo int: " + maximo(42, 17));
        System.out.println("Máximo str: " + maximo("banana", "abacaxi"));
    }
}

Collections

O Java Collections Framework oferece estruturas de dados genéricas e prontas: List (ordenada, com duplicatas), Set (sem duplicatas), Map (chave/valor).

List, Set, Map e ordenação 
import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {

        // List — mantém ordem, permite duplicatas
        List<String> nomes = new ArrayList<>(
            Arrays.asList("Ana", "Bruno", "Ana"));
        System.out.println("List: " + nomes);

        // Set — sem duplicatas
        Set<String> cidades = new HashSet<>(
            Arrays.asList("SP", "RJ", "SP"));
        System.out.println("Set size: " + cidades.size());

        // Map — chave/valor
        Map<String, Integer> estoque = new HashMap<>();
        estoque.put("Caneta", 50);
        estoque.put("Papel", 200);
        estoque.put("Caneta", 60); // substitui
        estoque.forEach((k,v) ->
            System.out.println(k + ": " + v));

        // Ordenação com Comparator (lambda)
        List<String> frutas = new ArrayList<>(
            Arrays.asList("banana", "uva", "abacaxi"));
        frutas.sort(Comparator.comparingInt(String::length));
        System.out.println("Ordenado por tamanho: " + frutas);
    }
}

Enum

enum define um conjunto fixo de constantes nomeadas. Pode ter atributos, construtores e métodos — é uma classe especial.

DiaSemana enum 
enum DiaSemana {
    SEGUNDA("Seg", false), TERCA("Ter", false),
    QUARTA("Qua", false),  QUINTA("Qui", false),
    SEXTA("Sex", false),   SABADO("Sáb", true),

    final boolean fds;

        for (DiaSemana d : DiaSemana.values()) {
            System.out.printf("%s (%s) fds=%b ordinal=%d%n",

        System.out.println("\nHoje: " + hoje.abrev +

}

Threads e Concorrência

Uma thread é uma linha de execução independente. synchronized garante que apenas uma thread execute um bloco por vez, evitando condições de corrida.

Thread, Runnable e synchronized 
public class ThreadsDemo {

    static class Contador {
        private int valor = 0;
        synchronized void incrementar() { valor++; }
        int getValor() { return valor; }
    }

    public static void main(String[] args) throws InterruptedException {

        // Criando thread com lambda (Runnable)
        Thread t1 = new Thread(() ->
            System.out.println("Thread " + Thread.currentThread().getName() + " rodando"));
        t1.start();
        t1.join(); // aguarda terminar

        // Contador com sincronização
        Contador c = new Contador();
        Thread ta = new Thread(() -> { for(int i=0;i<5000;i++) c.incrementar(); });
        Thread tb = new Thread(() -> { for(int i=0;i<5000;i++) c.incrementar(); });
        ta.start(); tb.start();
        ta.join();  tb.join();
        System.out.println("Contador (esperado 10000): " + c.getValor());

        // sleep
        System.out.println("Dormindo 100ms...");
        Thread.sleep(100);
        System.out.println("Acordou!");
    }
}

public class JdbcBasico {

Padrão DAO (Data Access Object)

Isola toda a lógica de banco em uma classe dedicada. O restante da aplicação só conhece a interface do DAO — independente do JDBC.

ProdutoDAO.java 
public class ProdutoDAO {
    private final Connection conn;
    public ProdutoDAO(Connection c) { conn = c; }

    public void inserir(Produto p) throws SQLException {
        try (PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO produtos (nome,preco) VALUES (?,?)")) {
            ps.setString(1, p.getNome());
            ps.setDouble(2, p.getPreco());
            ps.executeUpdate();
        }
    }

    public List<Produto> listarTodos() throws SQLException {
        List<Produto> lista = new ArrayList<>();
        try (ResultSet rs = conn.createStatement()
                .executeQuery("SELECT * FROM produtos")) {
            while (rs.next())
                lista.add(new Produto(rs.getInt("id"),
                    rs.getString("nome"), rs.getDouble("preco")));
        }
        return lista;
    }
}
